已接入 `index.html`。预览页 `hero-preview.html` 和 Replay 按钮已删除；`hero.js` 里那段 replay 绑定用 `if (btn)` 守着，想再调节奏时在 `index.html` 里加一行 `<button class="hx-replay">` 即可，样式还在 `hero.css`。

## 可调参数位置

* `hero.js` 顶部 `DUR = 4400` — 预览版放慢后的入场总时长；星星、英文、中文依次有更清楚的停顿
* `hero.js` `frame()` 里每段的 `seg(t, 起, 止)` — 各分镜时间点
* `hero.js` `setFinal()` 的 `--gi` — 静止时鼠标光泽强度（现 0.42）
* `hero.css` `.hx-shift` 的 `5px / 4px`、`.hx-bg` 的 `3px` — 鼠标位移幅度
* `hero.js` `onScrollFrame()` 的 `innerHeight * .9` — 过渡滚动长度
* `hero.css` `@media` 里的 `132% / 142%` — 手机端字标大小

## 已知限制

* 星星与字标之间的遮挡关系来自原图层合成，不是真实 3D；不能旋转。
* `拆分/字体.png` 只有 1331px，放大到终稿要 1.83 倍会糊，所以改从 2412px 的 `中文字.png` 里切星星，质量更好。`拆分/星.png` 留给后续做光标。
* 鼠标光泽用的是原始光效层 + 跟随指针的径向遮罩。光效层本身是字形形状，所以不会照出矩形边框，但它比字形略大，属于原素材特性。
* 背景/素材1.png、素材2.png 用途仍不明（叠加均使终稿误差变大），本轮未用。
* 异界重启矢量字体.ai 未解析，本轮未用。

## 定稿记录（2026-09-20）

* 开场总时长 **4.4 秒**（初版 2.4 秒偏快，已按反馈放慢并定稿）。
* `site-background.css` 让首页各区块与案例弹窗共用美工的 `背景+噪点质感`（网页优化版 `bg.webp`），全站背景连续、无接缝。
* hero 不再画自己的 `bg.webp`（`site-background.css` 里 `display:none`）。它和 body 的共用背景是同一张图，但 body 那张带 18% 压暗，hero 那张不带，叠在一起首屏明显更亮，滚动缩放时还会露出矩形硬边。改成只用共用背景后首屏和下面各区块亮度一致。
* 棱镜光仍属于 hero，但底部加了渐隐遮罩，避免滚过 hero 时留下一条水平切断线。实测接缝处亮度差已从 22.3 / 12.0 降到 11.1 / 12.0。
* 星星鼠标光标仍未做，后续单独一轮。
